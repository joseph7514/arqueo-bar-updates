# Arqueo Bar — actualizaciones

Archivos del actualizador a distancia de la app Arqueo Bar.
- `arqueo.json` — manifiesto (versión + enlace al bundle + huella sha256).
- `arqueo-v<N>.zip` — la interfaz de la app.

En el celular: Más > Actualizaciones > pegar la URL del arqueo.json > Buscar actualización.
